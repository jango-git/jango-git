# Hey, I'm Jango 👋

I do technical art for real-time 3D on the web. The badge says "developer", but most of my day is pipelines, tooling, and helping art and code meet in the middle.

My current territory is **mobile playable ads** - interactive 3D scenes that have to fit into ~5 MB. In practice that means:

- 🏗️ maintaining the 3D project template my team builds playables on
- 📦 owning the asset pipeline: compression, repacking, normalization, packaging
- 🧯 being the *"can we even fit that in 5 MB?"* person for designers and developers

Stack today: **Three.js + TypeScript**. Roots: **C++ / OpenGL**.

## Tools I build (and mostly use at work)

- <img src="sparcoon_logo.svg" width="18" height="18" alt="" /> **[sparcoon-editor](https://github.com/jango-git/sparcoon-editor)** - browser node editor for Three.js visual effects: graphs, timeline, live preview. Exports one self-contained TypeScript module, built for the 5 MB world.
- <img src="tesselot_logo.svg" width="18" height="18" alt="" /> **[tesselot](https://github.com/jango-git/tesselot)** - browser editor that turns photos into low-poly art: draw guides, triangle edges follow them. Exports SVG / PDF / PNG.
- 📱 **[laymur](https://github.com/jango-git/laymur)** - constraint-based UI toolkit for Three.js playables.
- 🧩 **[three-zoo](https://github.com/jango-git/three-zoo)** - small 3D components I keep reusing.
